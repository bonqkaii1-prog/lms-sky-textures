# lms-sky-textures

Staging for the Shattered Memories LMS skies (v3). Roblox Studio uploads these as image assets.

- `v3/<killer>_{Ft,Bk,Lf,Rt,Up}.png` — 1024² skybox faces (Roblox convention), generated from the reference art
- `v3/c00lkidd_doodles.png` — c00lkidd's 4×4 doodle-tile atlas (cut from the reference)
- `v3/u_*.png` — shared sprites: chain links, glow, butterfly flipbook, petal, eye flipbook, sparkle, beam, square
- `v3/test_*` — labelled orientation test sky
- `v3/upalt/` — spare rotations of every Up face (only used if the orientation test calls for them)
