# Cabin chess scene

Import into Roblox Studio:

- `models/`: all 11 `.fbx` files, with the 3D Importer.
- `textures/`: all 49 `.png` files, with Asset Manager bulk import. If the import stalls, do it in two batches.

`source/` holds the Blender scripts, the move loop (`loop.json`) and the client animation script. Do not import anything from it.
